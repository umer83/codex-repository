# Global Codex Instructions

- For non-trivial implementation work, use `$codebase-reuse` to find and reuse existing code before creating new code.
- Keep project-specific architecture, framework conventions, and product rules in that project's own `AGENTS.md` or equivalent instructions.
- Prefer targeted searches, relevant file reads, and existing indexes over broad repository scans.
- Reuse existing components, services, hooks, utilities, types, API logic, validation, constants, and tests when they fit.
- Make the smallest correct change, avoid unrelated refactors, and verify with focused checks scaled to risk.
